## 2. Language Context (`lib/LanguageContext.js`)

Gunakan React Context untuk membagikan state bahasa aktif ke seluruh komponen landing page secara global:

```jsx
'use client';

import { createContext, useContext, useState, useEffect } from 'react';
import { DICTIONARIES } from './dictionaries';

const LanguageContext = createContext();

export function LanguageProvider({ children }) {
  const [lang, setLang] = useState('id');

  // Load preferensi bahasa dari localStorage jika ada
  useEffect(() => {
    const savedLang = localStorage.getItem('gradivus_lang');
    if (savedLang) setLang(savedLang);
  }, []);

  const changeLanguage = (newLang) => {
    setLang(newLang);
    localStorage.setItem('gradivus_lang', newLang);
  };

  const t = DICTIONARIES[lang]; // Shortcut panggil terjemahan

  return (
    <LanguageContext.Provider value={{ lang, changeLanguage, t }}>
      {children}
    </LanguageContext.Provider>
  );
}

export function useLanguage() {
  return useContext(LanguageContext);
}
```

## 3. Cara Penggunaan di Komponen

Bungkus halaman utama Anda dengan `LanguageProvider` di `app/layout.js`, kemudian panggil hook `useLanguage` di dalam komponen client-side:

### A. Di `app/layout.js`:
```jsx
import { LanguageProvider } from '@/lib/LanguageContext';

export default function RootLayout({ children }) {
  return (
    <html lang="id">
      <body>
        <LanguageProvider>
          {children}
        </LanguageProvider>
      </body>
    </html>
  );
}
```

### B. Di `components/Hero.js` (Ubah menjadi `'use client'`):
```jsx
'use client';

import { useLanguage } from '@/lib/LanguageContext';

export default function Hero() {
```

## 4. Tombol Toggle Bahasa (`components/LanguageToggle.js`)

Buat tombol sederhana untuk berpindah bahasa yang bisa diletakkan di Navbar:

```jsx
'use client';

import { useLanguage } from '@/lib/LanguageContext';

export default function LanguageToggle() {
  const { lang, changeLanguage } = useLanguage();

  return (
    <div className="flex items-center bg-bg-card border border-border rounded-full p-1 gap-1">
      <button
        onClick={() => changeLanguage('id')}
        className={`px-3 py-1 rounded-full text-xs font-semibold transition-all ${
          lang === 'id' ? 'bg-accent-purple text-white' : 'text-text-secondary hover:text-white'
        }`}
      >
        ID
      </button>
      <button
        onClick={() => changeLanguage('en')}
        className={`px-3 py-1 rounded-full text-xs font-semibold transition-all ${
          lang === 'en' ? 'bg-accent-purple text-white' : 'text-text-secondary hover:text-white'
        }`}
      >
        EN
      </button>
    </div>
  );
}
```

## 5. Penyusunan WhatsApp Template Helper

Gunakan helper functions terpusat di dalam component atau library kustom untuk menyusun format pesan WhatsApp dari state kalkulator atau form kontak secara dinamis:

```javascript
// lib/whatsapp-helper.js

import { formatRupiah } from './constants';

/**
 * Merakit string teks untuk dikirim ke API WhatsApp
 * @param {Object} data - Berisi nama, brand, paket terpilih, dll
 * @returns {string} - Pesan terformat untuk link WA
 */
export function buildContactMessage({ name, business, pkg, notes }) {
  return [
    'Halo Gradivus Code!',
    '',
    `Saya *${name}* dari *${business}*.`,
    `Saya tertarik memesan paket: *${pkg}*.`,
    notes ? `\nCatatan tambahan:\n_${notes}_` : '',
    '',
    'Mohon informasi lebih lanjut untuk memulai proyek. Terima kasih!'
  ].filter(Boolean).join('\n');
}

/**
 * Merakit string teks dari kalkulator harga
 * @param {Object} selections - Berisi jenis website, branding, dan addons
 * @param {number} total - Estimasi total harga
 * @returns {string} - Pesan terformat untuk link WA
 */
export function buildCalculatorMessage(selections, total) {
  const addonList = selections.addons.length > 0 
    ? selections.addons.map(a => `- ${a}`).join('\n') 
    : '- Tidak ada';

  return [
    'Halo Gradivus Code, saya telah mencoba kalkulator harga dan tertarik memesan:',
    '',
    `*Jenis Website:* ${selections.website}`,
    `*Kebutuhan Branding:* ${selections.branding}`,
    `*Fitur Tambahan:* \n${addonList}`,
    '',
    `*Estimasi Total:* *${formatRupiah(total)}*`,
    '',
    'Mohon info lebih lanjut untuk konsultasi. Terima kasih!'
  ].join('\n');
}
```

## 6. Copywriting Brand Voice Guidelines

Dalam landing page, gunakan copywriting yang menarik, ringkas, dan persuasif dengan target pasar pelaku UMKM:

| Lokasi | Teks/Copy | Tujuan Bisnis |
|---|---|---|
| **Hero Title** | Bikin Usahamu **Naik Kelas** dengan Website Estetis & Super Cepat | Menangkap ketertarikan awal, menonjolkan value estetika & performa speed. |
| **Hero Subtitle** | Paket lengkap Landing Page + Branding untuk UMKM. Desain premium, performa ringan, harga mulai **Rp 1,5 juta**. Tanpa biaya bulanan. | Mengatasi keraguan utama: harga yang terjangkau, include branding, dan zero hosting cost bulanan. |
| **Calculator Subtitle** | Pilih kebutuhan Anda dan lihat estimasi biaya secara real-time. Tanpa komitmen! | Mendorong engagement agar pengunjung berani mencoba mengklik pilihan. |
| **CTA Buttons** | Pesan Sekarang via WhatsApp / Konsultasi Gratis | Menghilangkan batasan ragu (kata "Gratis" dan direct WA chat terasa personal). |

## 7. Dynamic Rendering vs Static Hardcoding

Next.js mengizinkan kita memisahkan konten ke dalam bagian yang static (di dalam file JSX) dan dinamis (dari database Supabase).

| Tipe Konten | Lokasi Penyimpanan | Metode Update |
|---|---|---|
| Hero Title, Subtitle, Deskripsi Layanan | Hardcoded di JSX (`components/Hero.js`) | Edit kode langsung jika visi brand berubah. |
| Harga paket & Addons | Javascript constant (`components/Calculator.js`) | Edit object `CALC_PRICING` (lihat reference-data). |
| FAQ Accordion | Javascript constant (`components/FAQ.js`) | Edit array `FAQ_ITEMS` jika ada pertanyaan baru. |
| **Portofolio Galeri** | Database **Supabase** | Kelola via dashboard Admin `/admin` secara dinamis (tanpa sentuh kode). |

## Rules

1.  **localStorage Sync:** Setiap kali user mengganti bahasa, pilihan bahasa wajib disimpan ke `localStorage` agar bahasa tetap sama saat halaman di-refresh.
2.  **Server Components Warning:** Jika komponen utama dibungkus Provider, pastikan child component interaktif yang menggunakan teks dinamis dideklarasikan sebagai Client Component (`'use client'`).
3.  **Fallback Text:** Jika kunci terjemahan pada kamus `en` kosong, buat fallback otomatis ke bahasa `id` agar tidak merender string kosong di layar browser.
4.  **Single Source of Whatsapp Template:** Pembuatan format text pesan WhatsApp dilarang ditulis acak di sembarang file. Gunakan fungsi pembantu (helper) dari file terpisah agar jika format dirubah, perubahannya seragam.
5.  **Use "Anda" instead of "Kamu":** Gunakan sapaan profesional yang sopan "Anda" untuk membangun reputasi agensi terpercaya.
6.  **Use `encodeURIComponent`:** Semua perakitan link WhatsApp wajib membungkus output string template menggunakan method native `encodeURIComponent(message)` agar space dan karakter khusus ter-parse dengan aman oleh API browser.
7.  **No Dynamic Database Call for FAQs:** Untuk FAQ, karena isinya statis dan tidak sering berubah, jangan menaruhnya di database. Taruh di file Javascript constant agar loading speed tetap maksimal.
